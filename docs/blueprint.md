# **App Name**: Artisanal Adornments

## Core Features:

- Product Catalog: Showcase available handcrafted jewelry with photos and descriptions. Prices are hidden; a 'Contact Us for More Information' button appears on the product page.
- Custom Order Form: Allow customers to submit custom jewelry requests with descriptions, materials, and size.
- Order Management: Allow users to track orders.
- AI Design Assistant: A tool that helps users refine their custom design ideas. Includes a text input to generate images based on the customer's textual request, powered by Gemini with Imagen for visualizations.
- Inspiration Gallery: Display user-submitted photos wearing jewelry.
- Automatic Translation: Automatic translation based on user location.
- Switzerland Language Selection: Prompt users in Switzerland to choose a language (German, French, Italian, English) upon first visit.
- Navigation Menu: Top menu with 'Home', 'Gallery', 'Custom Jewel', 'About Us', and 'Contact' links, inspired by grimajewellery.com.

## Style Guidelines:

- Primary color: Soft gold (#D4A989) to convey elegance and craftsmanship.
- Background color: Light beige (#F5F5DC), offering a neutral backdrop to highlight the jewelry.
- Accent color: Bordeaux (#800020) for buttons and key interactive elements.
- Headline Font: 'Belleza' sans-serif with a style aligned to fashion, art, and design. Body Font: 'Lora' a serif to complement with an elegant, intellectual feel
- Use line icons representing materials, gemstones, or design tools. Refined style.
- Clean layout to present the products at its best.
- Subtle transitions on product hover. Parallax scrolling.
